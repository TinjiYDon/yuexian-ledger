# 赛题一 · DataClawHub 运营方案

这份与赛题二检查台分开交。目标是让更多人打开并试用「先别申报」制品，留下可核对的访问、注册、激活数据。

## 目标用户

校园里做物流、数据或对单相关作业的同学（华东师大及周边高校）。只选这一类：他们能在一周内完成「打开制品 → 点一票红货 → 看到先别申报」，也最容易用专属邀请码统计。

## 平台卖点

在 DataClawHub 上交一份可打开的制品：`先别申报` 检查台（仓库 https://github.com/TinjiYDon/yuexian-ledger ，入口 `demo/index.html`）。一打开就能看见一票货被挡住发送，并标出该改的栏。卖点只这一句，不另讲系统架构。

## 渠道与节奏

主渠道：赛事互动群 + 学院同学转发专属邀请码。

| 日期 | 动作 |
| --- | --- |
| 上传当日 | 在 DataClawHub 赛事专区提交制品，标题含队伍名与「先别申报」 |
| 次日 | 群内发 30 秒录屏：列表红票 → 先别申报 → 两处毛重 |
| 晋级实测期 | 每天只催一次「打开制品并点进主票」，不换卖点 |

## 转化路径

访问 → 注册 → 打开制品 → 留下一次互动（点开主票或点赞）。

| 步骤 | 在平台上怎么数 |
| --- | --- |
| 访问 | 专属邀请码入口的打开次数 |
| 注册 | 经该邀请码完成的新注册 |
| 打开制品 | 「先别申报」制品详情页的打开次数 |
| 一次互动 | 点赞，或评论里留下「已点开主票」 |

## 复盘

晋级后按上面四列导出，做成一张表：日期、访问、注册、打开、互动。只复盘这一条漏斗，不扩第二渠道。若某一天打开高、互动低，第二天的群消息只补一句「点进红色那票看先别申报」。
