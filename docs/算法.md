# 算法

## 出生站

同一字段只保留标签为「站点改写」的值，按订舱、装箱、提单、舱单、报关单排序。与上一站的值第一次不同的站点，就是出生站。标签为「抽取误差」的值不进入这条序列。

## 毛重

比较装箱单与提单的毛重。绝对差除以提单毛重，大于 0.03 则挡住申报。0.03 来自公开海运清关说明，不是法条。

## 柜号和封条

提单与舱单的值必须相同。出现第二版就挡住，出生站按上面的规则算。

## 四国口径

单证上若只有一个「国家」栏，且它等于原产国、又不等于贸易国，视为四套口径被写成一格，挡住申报。四栏分开写则通过这一条。

## 总判定

任一条挡住，结论是「先别申报」。没有任何一条挡住，结论是「可以申报」。解释文本不允许改这个结论。
